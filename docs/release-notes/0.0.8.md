# Lighthouse 2 0.0.8

Better at telling "done" from "needs you".

- **Needs you** now follows what the run needs, not just how it ends. With
  summaries on, the summary model also answers one question: can this thread
  go on without you? A finished run, a report of results, or an optional offer
  ("install it if you like") is not "needs you". A question, a choice, an
  approval, or a task for you (sign in, test, send a file) is. A thread where
  you wrote the last message never counts.
- With summaries off, Lighthouse uses stricter wording rules on your Mac: only
  the last paragraph, and quoted examples are ignored.
- When something needs you, the menu bar shows a red ◆ and the count before
  the lighthouse. The panel no longer repeats it at the top; each project still
  has its yellow tag.

Summaries made before this update are judged once more for finished threads
from the last two hours, within your hourly call limit. Settings and the store
carry over from 0.0.7.
