# Lighthouse 2 0.0.15

Resolving a counted T3 Code request or resuming a reply hand-off now clears its red count in about a second.

- While a T3 Code thread counts toward **Needs you**, Lighthouse watches T3's
  database for changes and re-reads just those threads when one happens.
  Resolving an approval or input request, or resuming a reply hand-off, clears
  that item without waiting for the next full read.
- This covers requests and reply hand-offs that are already counted, including
  subagent requests. An alert for a thread still stuck after 3 nudges clears
  on the fast path when its run ends or the thread is deleted. Progress recorded
  only in session logs waits for the regular full read.
- New waits and everything else still appear on the regular full read, about
  once a minute. Claude Code and Codex app threads are unchanged.
- The extra check reads T3's database in place, read-only, as before. It runs
  only while a T3 Code thread is counted.

Already on 0.0.14? Use the **Update** button in the panel. Settings and the
store carry over from 0.0.14.
