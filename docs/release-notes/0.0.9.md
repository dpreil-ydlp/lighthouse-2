# Lighthouse 2 0.0.9

No more Keychain prompts.

- Claude usage needs Claude Code's sign-in token from the Keychain. Lighthouse
  now reads it through Apple's `/usr/bin/security`, the same tool Claude Code
  uses for that item, so macOS no longer asks, and updates do not bring the
  prompt back. Before, "Always Allow" was tied to Lighthouse's own signature,
  which changes with every update.
- If you allowed an older version, you can remove Lighthouse 2 from the item's
  Access Control list in Keychain Access; it no longer needs the entry.

Includes 0.0.8 (Needs you judged by what the run needs; red ◆ and count before
the menu bar logo). Settings and the store carry over.
