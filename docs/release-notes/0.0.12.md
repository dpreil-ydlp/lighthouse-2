# Lighthouse 2 0.0.12

See exactly which threads need you.

- When a project says **Needs you · 2**, open it: the threads that need you are
  listed first, each with its own yellow **Needs you** tag.
- Click a thread's **Needs you** tag to open that thread in its app. T3 Code
  opens the exact thread; Claude and Codex open their app. On the
  project row, the tag opens the thread when only one waits, and expands the row
  when several do.

Settings and the store carry over from 0.0.11.
