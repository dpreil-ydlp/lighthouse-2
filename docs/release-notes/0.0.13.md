# Lighthouse 2 0.0.13

Lighthouse can now kick a stalled T3 Code thread back into work.

- Turn on **Nudge stalled T3 Code threads** in Settings › Sources. It is off
  until you do.
- When a T3 Code thread has made no progress for 30 minutes, Lighthouse sends
  it a short message asking it to continue or say what it needs. Up to 3
  nudges, 15 minutes apart.
- If it is still stuck after the third, the thread shows as **Needs you**
  ("Still stuck after 3 nudges"), with the red count in the menu bar.
- Only T3 Code parent threads are nudged. Subagents, Claude Code threads and
  Codex app threads are never messaged.
- Turning it on connects to T3 Code on this Mac with Full access (T3 refuses
  messages to threads with more access than the connection). The token stays
  in a private file and is revoked when you turn the switch off.

Settings and the store carry over from 0.0.12.
