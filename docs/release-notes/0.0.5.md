# Lighthouse 2 0.0.5

A more compact panel.

- Click **USAGE** at the top to fold usage to one line per provider: percent
  left for the session and the week. Click again for the full view with pace
  and reset times. The choice is saved.
- Each project's status (Working, Recent, No activity) is now on the first line
  beside the app labels. The thread count is gone, so each row is one line
  shorter.
- A yellow **Needs you** tag marks a project whose thread or subagent waits for
  your approval or answer. Hover it to see which.
- With many projects the panel can grow to nearly the full screen height.

Settings and the store carry over from 0.0.4.
