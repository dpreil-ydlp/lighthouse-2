# Lighthouse 2 0.0.6

Fixes and a tidier top of the panel.

- The gear now opens Settings in front of your other windows. Before, the
  window opened behind the app you were in, so the click seemed to do nothing.
- The search field is always visible at the top, beside the name. Typing
  anywhere in the panel still starts a search, and ⌘F focuses the field.
- Usage opens compact, one line per provider. Click **USAGE** for pace and
  reset times; the choice is saved.
- Hovering a project shows a short "T3 Code ↗" button on one line, so the row
  keeps its height.

Settings and the store carry over from 0.0.5.
