# Lighthouse 2 0.0.2

First public release of Lighthouse 2, a macOS menu bar app that shows your Claude and Codex usage left, which coding agent needs you, and your projects with their threads and subagents. It only watches; it never controls an agent.

## In this release

- The app is named Lighthouse 2 and installs as `/Applications/Lighthouse 2.app`. The bundle id stays `com.lighthouse.v2`, so settings and permissions from earlier private builds carry over. The installer moves an older `/Applications/Lighthouse.app` to the Trash.
- Usage bars for Claude (session and week) and Codex, with the percent left, reserve or deficit against an even pace, and when the current pace runs out.
- One line for what needs you: approvals waiting, agents gone quiet, stalled threads.
- Projects, threads and subagents from Claude Code, Codex and T3 Code, with Open buttons that go to the owning app.
- Optional one-line thread summaries through your own `claude` or `codex` CLI. Off by default; when on, recent conversation text goes to the provider you pick.

## Known limits

- Signed ad-hoc and not notarized. A browser download needs Open Anyway once; the command-line install does not.
- Apple silicon only. macOS 14 or later is declared; this release ran on macOS 26.5 and was built and tested on 26.6. Earlier versions are untested.
- Claude and Codex links open the app, not the exact thread. T3 Code links open the exact thread.
