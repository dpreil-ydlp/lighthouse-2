# Lighthouse 2 0.0.16

Settling a T3 Code thread now takes it out of **Needs you**.

- When you settle a thread in T3 Code, everything it raised up to that moment
  leaves Needs you, Gone quiet, the red count and notifications. That includes
  reply hand-offs, approval and input requests, subagent requests, stalls and
  the "still stuck after 3 nudges" alert.
- Anything the thread raises after you settle it still shows up.
- Settling a thread that is already counted clears it in about a second, the
  same way answering a request does.
- Lighthouse no longer nudges a settled thread about a stall that started
  before you settled it.
- Unsettled threads, Claude Code and the Codex app are unchanged. Lighthouse
  still reads T3's database in place, read-only.

Already on 0.0.14 or 0.0.15? Use the **Update** button in the panel. Settings
and the store carry over.
