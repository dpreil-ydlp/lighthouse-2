# Lighthouse 2 0.0.14

Lighthouse now tells you when a new version is out and updates itself in one click.

- When a newer release exists, an **Update** button appears at the top of the
  panel.
- Hover it to see what changes: every release between yours and the newest,
  newest first.
- Click it to update. Lighthouse downloads the new version from GitHub, checks
  its SHA-256, replaces itself and opens again. If anything fails, your copy
  stays as it was.
- Lighthouse checks at launch and every 6 hours. Settings › General › Updates
  has **Check now** and a switch to turn the automatic checks off.
- The check asks GitHub for the public release list. Nothing about you or your
  Mac is sent.

This is the last update that needs the install command. From 0.0.14 on, use
the button. Settings and the store carry over from 0.0.13.
